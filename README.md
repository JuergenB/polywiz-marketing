# PolyWiz Marketing Site

Marketing and landing page for [PolyWiz](https://polywiz.polymash.com) — the campaign planning tool that gives arts organizations, nonprofits, and creative institutions sustained social media presence across 14 platforms.

## About PolyWiz

Arts organizations promote exhibitions, events, newsletters, and artist features — but most get a single social post on launch day, then silence. PolyWiz solves the "one post on opening night" problem by generating and scheduling dozens of platform-specific posts over weeks and months, with human approval before anything goes live.

**Built by [Polymash](https://polymash.com) for the arts and 501(c)(3) sector.**

### Key Capabilities
- **Campaign Planner** — Paste a URL, get a multi-week campaign
- **AI Post Generator** — Platform-tuned drafts via Claude AI
- **Smart Scheduler** — Tapering algorithm for sustained promotion
- **Approval Queue** — Nothing goes live without team review
- **14-Platform Publisher** — Instagram, LinkedIn, X, Threads, Bluesky, TikTok, and more
- **Multi-Brand Support** — One tool for all your organizations
- **Image Optimizer** — Auto-crop, compress, AI-extend for each platform
- **Branded Link Shortener** — UTM tracking built in

### Built For
- Arts organizations and galleries
- 501(c)(3) nonprofits
- Newsletter publishers
- Podcast networks
- Event coordinators
- Small creative teams doing more with less

## Tech Stack
- Next.js 16 / React 19 / TypeScript
- Tailwind CSS v4
- Framer Motion
- Deployed on Vercel

## Getting Started

```bash
npm install
```
